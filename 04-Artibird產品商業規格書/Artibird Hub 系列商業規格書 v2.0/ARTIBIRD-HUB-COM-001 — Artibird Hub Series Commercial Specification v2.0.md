**EN**

在必要的本地設備、網路及 Runtime 服務仍正常的條件下，即使外部雲端連線中斷，受支援的場景、設備控制及自動化仍可在本地持續運行。

**Customer Benefit｜客戶收益**

Greater operational continuity and reduced dependence on external cloud connectivity.

提升運行連續性，減少對外部雲端連線的依賴。

### 3.2 Spatial Control｜空間控制

**EN**

Control rooms and spaces through a unified interface. View supported devices, activate scenes, adjust environmental settings, and track command results.

**繁中**

透過統一介面管理房間與空間，查看受支援設備、啟動場景、調整環境設定，並追蹤控制命令的實際結果。

**Customer Benefit｜客戶收益**

Simpler operation across rooms, devices, and everyday activities.

簡化多房間、多設備及日常活動的操作。

### 3.3 Coordinated Automation｜協同自動化

**EN**

Create coordinated behaviors across supported Artibird devices, including lighting, air conditioning, curtains, environmental sensors, and power control.

**繁中**

讓受支援的 Artibird 設備共同參與自動化運行，包括照明、空調、窗簾、環境感測與電力控制。

**Customer Benefit｜客戶收益**

Reduce repetitive manual operations and improve consistency across spaces.

減少重複人工操作，提升空間運行的一致性。

### 3.4 Operational Visibility｜運行可視化

**EN**

Monitor device connectivity, runtime health, command execution, and system events through supported management interfaces.

**繁中**

透過管理介面監測設備連線、Runtime 健康狀態、命令執行及系統事件。

**Customer Benefit｜客戶收益**

Understand system conditions and identify issues more efficiently.

更容易掌握系統狀況，提高問題識別效率。

### 3.5 AI-Assisted Operations｜AI 輔助運維

**EN**

With supported OceanAI Operations Agent services, operators can analyze runtime logs, investigate faults, and generate evidence-based operational reports.

**繁中**

透過受支援的 OceanAI Operations Agent 服務，運維人員可分析 Runtime 日誌、調查故障並生成具有證據依據的運行報告。

**Customer Benefit｜客戶收益**

More efficient troubleshooting and better-informed maintenance decisions.

提升故障排查效率，協助運維人員作出更有依據的維護決策。
